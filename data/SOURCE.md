# Dataset attribution

Fanaee-T, H. (2013). **Bike Sharing** [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5W894

Source page: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset

Downloaded 2026-10-25 from https://archive.ics.uci.edu/static/public/275/bike+sharing+dataset.zip.

License stated by UCI: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/ . Credit remains with the dataset creator and source. Original source ZIP, hour.csv, day.csv and Readme.txt are retained. rentals.csv is an adapted, labeled version created by scripts/analyze.py; transformations and limitations are documented in this project.

Historical Capital Bikeshare rental counts for 2011–2012 with weather and calendar variables. The analyzed source contains 17,379 observed hourly records; the source website's displayed instance count differs. The file itself and daily-table reconciliation determine this project's count.
